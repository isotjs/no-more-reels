# Changelog

All notable project changes are documented in this file.

This format follows Keep a Changelog and uses Semantic Versioning.

## [3.1] - 2025-10-11

### Added

- Debug mode toggle in popup with immediate propagation.
- Docs and assets consolidation under `Docs/` and `Assets/`.

### Changed

- Popup feedback and version display improvements.
- Improved state synchronization for runtime updates.

## [3.0] - 2025-07-11

### Added

- Threads button hiding toggle.
- Debug mode support across popup/background/content.
- Interactive Reels/Explore tags in popup.

### Changed

- More robust selector coverage for dynamic Instagram UI.
- Better storage fallback behavior (`sync` -> `local`).
- Improved responsive behavior in popup UI.

## [2.0] - 2025-05-29

### Added

- Grayscale mode toggle.
- Multi-language support (EN, DE, FR, RU, TR).
- Expanded documentation set.

### Changed

- Migrated to Manifest V3 format.
- Improved MutationObserver-based content handling.

## [1.0] - 2025-05-28

### Added

- Initial release.
- Reels and Explore hiding in navigation and links.
- Blocking for direct `/reels/` and `/explore/` access.
- Persistent on/off setting.

## Notes

- Dates use `YYYY-MM-DD`.
- Keep entries concise and user-impact focused.
